# Genesis (коротко по-русски)

Маленький непрерывно живущий агент вокруг **трансформера, написанного с нуля на NumPy** (без PyTorch, без готовых моделей и без внешних LLM).
Он читает Википедию и книги, пишет и запускает код в песочнице, рисует, спит, вспоминает, **сам меняет свою архитектуру** (турниры с парным t-тестом)
и имеет внутреннее состояние (эмоции, тело, внимание), которое подаётся **прямо в сеть**, так что речь может зависеть от того, что у него внутри.

Это исследовательская площадка, а не продукт и **не заявление о сознании**: эмоции здесь функциональные переменные. Подробности и честные цифры
(в том числе то, что часть тестов самознания пока не лучше простых базовых методов) смотри в [README.md](README.md).

```bash
pip install -r requirements.txt
python3 genesis_web.py      # чат и «мозг»: http://127.0.0.1:8765
python3 -m unittest discover -s tests -v
python3 selftest.py         # батарея тестов самознания (нужна обученная сеть)
```

Старт с нуля = «рождение»: случайные веса, 3 слоя, 0.63 М параметров. Всё выученное (веса, словарь, память, чаты, рисунки) хранится локально и в git не попадает.
В обучающих примерах собеседник зовётся «Теодор» (имя автора), интерфейс на русском.
