# Research notes (draft, Russian)

Цель: максимум качества на единицу данных и CPU-времени. Судья: bpb (бит на байт) на отложенном корпусе
как функция минут CPU и числа просмотренных байт, против базы (текущий GN-NET: pre-LN трансформер + Adam).

## Что показала литература (первый заход; цифры авторские, не перепроверены)
| Идея | Источник | Что даёт малым моделям |
|---|---|---|
| Дельта-правило / быстрые веса (Gated DeltaNet, TTT, Titans) | arXiv 2412.06464, 2511.07343 | состояние = матрица, обновляемая онлайн; запоминает факт с одного раза; линейная цена по длине |
| Рекурсия с адаптивной глубиной (Mixture-of-Recursions) | arXiv 2507.10524 | общий стек слоёв + роутер на токен; меньше параметров и FLOPs при той же ошибке (135M–1.7B) |
| Динамическое разбиение байтов (H-Net) | arXiv 2507.07955 | модель сама режет байты на куски, обгоняет BPE-трансформер при тех же данных и вычислениях |
| Рекуррентные/линейные модели в BabyLM | arXiv 2412.15978, 2511.05560 | на малых данных рекуррентные гибриды обходят трансформеры; Muon лучше AdamW |
| Muon | arXiv 2509.24406, Keller Jordan | на 30–200M: та же ошибка за ~50% шагов Adam (по заявлению авторов) |
| Разреженная память (product-key memory, sparse memory finetuning) | arXiv 2510.15103 | дообучение только затронутых слотов: почти без забывания |
| Разреженные нейроны на CPU (SLIDE) | arXiv 1903.03129 | 1–5% нейронов за шаг; на CPU быстрее GPU на широких слоях (но на узких слоях выигрыша нет) |
| Самоигра на проверяемом коде (Absolute Zero) | arXiv 2505.03335 | задачи придумывает и решает сама модель, награда от исполнителя кода |

Решение автора: локальные правила обучения (predictive coding) пока вне плана.

## Кандидат на архитектуру «GN-X» (всё вместе, но проверяем по частям)
1. Вход: байты (без внешнего BPE) + динамическое разбиение на куски (идея H-Net); картинки/звук остаются атомарными токенами.
2. Ядро: ОДИН общий блок, прокручиваемый K раз; роутер решает на токен, сколько кругов (MoR).
   Блок = короткая свёртка + gated delta-память (быстрые веса) + малое локальное внимание.
3. Долгая память: product-key таблица слотов (разреженная, обновляется только прочитанное). Вместо MLP в части слоёв.
4. Оптимизатор: Muon для 2D-матриц, Adam для остального.
5. Рост (уже есть в Genesis): добавлять круги/слоты/ширину по плато, не меняя функцию.
6. Источник знаний: самоигра в песочнице (код + проверка) + чтение; награда = реальный прогресс.
